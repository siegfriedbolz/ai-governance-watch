# Code of Conduct

This project adopts the **Contributor Covenant v2.1** as its Code of Conduct.

The full canonical text is published at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## In short

- Be respectful. Assume good faith. Disagree about ideas, not people.
- This is an open, public-by-design project. Conversations happen on GitHub
  (issues, PRs, discussions) and stay on the record.
- Harassment, personal attacks, and discriminatory language are not
  acceptable.
- Project decisions are documented in PRs and issues, not in private DMs.

## Scope

This Code applies to all project spaces — the repository, issues, pull
requests, discussions, and any public communication where someone is
representing the project.

## Reporting

Report concerns privately through GitHub's
**[Security Advisory form](https://github.com/siegfriedbolz/ai-governance-watch/security/advisories/new)**
(it is visible only to the maintainer; note in the report that it is a
conduct matter). Reports are read by the project maintainer (currently a
single person), handled confidentially, and acknowledged within five
business days.

## Enforcement

The maintainer will apply the Contributor Covenant 2.1 enforcement ladder
(correction, warning, temporary ban, permanent ban) in proportion to the
severity and pattern of the behaviour. Decisions are documented in the
relevant issue or PR thread where appropriate, redacted where necessary.
